# 简体中文与英文切换实施清单

**目标：** 本地平台默认使用简体中文，允许切换英文并保留偏好。

**架构：** 根布局从 Cookie 读取语言，通过 React Context 提供 `t(english, chinese)`。翻译只作用于明确的界面文案；路由、接口、存储值、用户内容、第三方名称保持原值。独立组件没有 Provider 时保持英文，以兼容组件预览与现有测试。

**技术：** Next.js App Router、React Context、Cookie、Vitest、Playwright。不增加运行时依赖。
