# 外部对话归档

在 AutoGPT 左侧点击 **对话归档**，打开 `/chat-imports`。归档独立于可继续聊天的 Copilot 会话，只对导入账号可见；不会调用模型、执行工具或写回源应用。

## WorkBuddy：在网页上选择会话文件

1. 打开 **对话归档 → WorkBuddy → 选择会话文件**。
2. 在 Windows 文件选择框地址栏中打开 `%USERPROFILE%\.workbuddy\projects`，进入对应子文件夹，选择一个或多个 `.jsonl` 会话文件。不必运行脚本，也不要选择整个 `.workbuddy` 目录或 `workbuddy.db`。
3. 展开预览，勾选需要的会话。不需要附件时，直接选择 **保存选中对话**；只有勾选会话的标题、问答、时间和用于去重的标识会在确认后提交。
4. 需要附件时，确认 **原目录路径** 是会话引用所在的原始项目目录，再用 **选择附件目录** 授权浏览器读取该目录，并确认将所选目录对应到此原路径。浏览器只提供文件的相对路径，无法区分位于不同位置的同名目录。页面按路径匹配，不会仅凭文件名猜测；请核对匹配到的文件名、相对路径和大小。没找到的文件可以在相应会话的预览下 **手动选取附件**。
5. 附件默认不选。勾选会话及所需附件，再点击 **保存选中对话**；保存后可在归档详情下载。会话 `.jsonl` 原文件、结构化工具日志和未勾选的文件不会自动上传。若对话正文包含本机路径，该路径仍作为正文的一部分保存；匹配用的目录路径和引用不作为独立字段上传。

浏览器不会主动扫描用户目录；只能读取用户授权的文件和目录。直接导入 `.jsonl` 使用 HTTPS 或本机 `localhost`。目前支持已验证的 WorkBuddy 5.x 文本会话格式；自动匹配只识别部分文本路径和显式文件块，附件格式和存放位置可能因版本而异。页面不会读取客户端会话索引，也不会下载网络链接。只存在于云端或已不在本地的内容无法自动导入。之前生成的规范化 `.json` 文件仍可选择导入，并可手动添加附件。

## 千问：手动录入文本

在 **对话归档 → 千问** 粘贴要保留的问答，预览后确认导入。这里不调用千问私有接口、不读取浏览器缓存，也不假定账号支持批量导出。没有提供原始时间时，页面显示入库时间而非虚构原始时间。

## 运行与边界

- 启动前，按正常本机流程应用 PostgreSQL 迁移、重新生成 Prisma 客户端并启动新前后端。不要对现有数据执行 `migrate reset`。
- 同一 AutoGPT 账号内，直接导入 WorkBuddy 文件按会话 ID 的摘要去重，旧版 `.json` 导出包使用其已有标识，两种方式之间不保证去重。重复导入可以给已有归档补充附件，不会覆盖旧正文。千问手动导入按问答角色和正文去重。归档是快照，不跟踪编辑、删除或后续回复。
- 一次最多打开 25 个会话文件，合计不超过 32 MiB；最多选择 25 个会话，单个会话最多 500 条文本消息，选中的文本合计不超过 4 MiB。含附件的会话单独提交；若部分请求失败，已成功的归档会保留，重试不会重复写入相同会话和附件。
- 每个 WorkBuddy 归档最多 10 个附件，单文件不超过 5 MiB，累计不超过 10 MiB，后端 multipart 请求上限 16 MiB。Vercel 部署按每条会话正文和所选附件合计不超过 4 MiB 提交，为 multipart 请求头留出空间；其他部署网关也可能有更小的限制。附件需通过配置为失败即拒绝的 ClamAV 扫描后才存入 PostgreSQL，只允许归档所有者下载。删除归档会一并删除附件副本，不影响 WorkBuddy 或千问中的原记录。
